## Назначение проекта

Репозиторий содержит решения всех четырёх вариантов задания: от простого калькулятора
до расчёта стоимости покупки со скидками. Каждая программа — отдельный самостоятельный
Python-файл, который запускается из консоли и общается с пользователем через `input()` / `print()`.

Цель работы — освоить базовый синтаксис Python (условные конструкции, циклы, функции,
словари, обработку исключений), а также освоить работу с системой контроля версий Git
и удалённым репозиторием на GitHub.

Все программы решают общие задачи:

- ввод данных пользователем через консоль;
- обработка основных сценариев с помощью условных конструкций;
- обработка некорректных данных (не тот тип, пустая строка, недопустимое значение);
- циклический повтор операции без перезапуска программы.

## Требования и запуск

**Требования:** Python 3.6 или новее. Внешние библиотеки не используются — только стандартная
библиотека Python.

**Запуск:**

```bash
python 1.py
```

Аналогично для остальных файлов — замените имя файла на нужное (`2.py`, `3.py`, `4.py`).

Каждая программа работает в интерактивном режиме: она задаёт вопросы и ждёт ввода с клавиатуры.
Чтобы завершить работу, отвечайте `нет` на вопрос о повторении.

## Вариант 1. Консольный калькулятор — `1.py`

**Новое в практической работе №2:** возможность выполнять несколько вычислений подряд
без перезапуска программы.

**Что решает программа:**

- запрашивает первое число, математическую операцию и второе число;
- поддерживает операции `+`, `-`, `*`, `/`, `//`, `%`, `^` (возведение в степень);
- обрабатывает неизвестную операцию, деление на ноль и некорректный ввод чисел.

**Как пользоваться:** введите первое число, затем знак операции и второе число. После вывода
результата программа спросит `Хотите выполнить ещё одну операцию? (да/нет):` — ответ `да`
продолжает работу, любой другой ответ завершает программу.

**Пример работы:**

```
Доступные операции: +, -, *, /, //, %, ^ (возведение в степень)
Введите первое число: 10
Введите операцию: *
Введите второе число: 5
Результат: 50
Хотите выполнить ещё одну операцию? (да/нет): да
Введите первое число: 100
Введите операцию: /
Введите второе число: 4
Результат: 25.0
Хотите выполнить ещё одну операцию? (да/нет): нет
Программа завершена
```

**Обработка ошибок:**

| Ситуация | Поведение |
| -------- | --------- |
| Введено не целое число | `Ошибка: введите целое число. Попробуйте снова.` — запрос повторяется |
| Деление на ноль | `Ошибка: деление на ноль!` |
| Неизвестный знак операции | `Ошибка: неизвестная операция` |

> Реализация: операции хранятся в словаре лямбда-функций, ввод чисел защищён циклом
> `while True` с `try / except ValueError`.

## Вариант 2. Конвертер единиц — `2.py`

**Новое в практической работе №2:**

1. возможность выполнять несколько преобразований подряд;
2. добавлены **два новых вида преобразования**, которых не было в первой работе
   (литры → галлоны и мегабайты → гигабайты).

**Что решает программа:** переводит значение из одной единицы измерения в другую.

**Доступные преобразования:**

| № | Преобразование | Формула |
| - | -------------- | ------- |
| 1 | Градус Цельсия → Градус Фаренгейта | `C × 9 / 5 + 32` |
| 2 | Километры → Мили | `км × 0.621371` |
| 3 | Килограммы → Фунты | `кг × 2.20462` |
| 4 | Метры → Футы | `м × 3.28084` |
| 5 | Литры → Галлоны | `л × 0.264172` |
| 6 | Мегабайты → Гигабайты | `Мб / 1024` |

**Как пользоваться:** выберите номер преобразования, введите значение. После вывода результата
программа спросит `Выполнить ещё одно преобразование? (да/нет):` — ответ `да` возвращает
к меню выбора.

**Пример работы:**

```
Выберите конвертер:
1. Градус Цельсия - Градус Фаренгейта
2. Километры - Мили
3. Килограммы - Фунты
4. Метры - Футы
5. Литры - Галлоны
6. Мегабайты - Гигабайты
Ваш выбор: 2
Введите расстояние в километрах: 10
10 км = 6.21 миль
Выполнить ещё одно преобразование? (да/нет): да
```

**Обработка ошибок:**

| Ситуация | Поведение |
| -------- | --------- |
| Номер преобразования не целое число | `Ошибка: нужно ввести целое число от 1 до 4!` |
| Номер вне диапазона 1–6 | `Ошибка: неизвестный номер преобразования! Допустимы только 1, 2, 3, 4.` |
| Значение не является числом | `Ошибка: нужно ввести число (можно с десятичной частью).` |

> Результат выводится без лишних нулей: `36 C = 96.8 F`, `10 км = 6.21 миль`.

## Вариант 3. Проверка характеристик числа — `3.py`

**Новое в практической работе №2:**

1. возможность анализировать несколько чисел подряд;
2. добавлено определение, **является ли число квадратом целого числа** (полным квадратом).

**Что решает программа:** анализирует введённое целое число и выводит его характеристики.

**Определяемые характеристики:**

- положительное / отрицательное / ноль;
- чётное или нечётное;
- делится ли на 3;
- делится ли на 5;
- простое ли число;
- количество цифр;
- является ли число квадратом целого числа (полный квадрат).

**Как пользоваться:** введите целое число. После вывода характеристик программа спросит
`Проверить ещё одно число? (да/нет):` — ответ `да` запрашивает новое число.

**Пример работы:**

```
Введите число: 17
Ваше число: 17
Положительное: да
Является квадратом целого числа: нет
Отрицательное: нет
Ноль: нет
Четное: нет
Делится на 3: нет
Делится на 5: нет
Простое: да
Количество цифр: 2
Проверить ещё одно число? (да/нет): да
Введите число: 49
Ваше число: 49
Положительное: да
Является квадратом целого числа: да
...
```

**Обработка ошибок:**

| Ситуация | Поведение |
| -------- | --------- |
| Введено не целое число | `Ошибка! Введите целое число.` — запрос повторяется |

> Проверка на простоту выполняется перебором делителей до `√n`, проверка на полный квадрат —
> через `int(n ** 0.5)` и сравнение `root * root == num`.

## Вариант 4. Расчёт стоимости покупки — `4.py`

**Новое в практической работе №2:**

1. возможность добавить **несколько товаров в одну покупку**;
2. подсчёт общей стоимости, скидки и итоговой суммы по всей покупке.

**Что решает программа:** последовательно запрашивает товары, суммирует их стоимость
и применяет скидку в зависимости от суммы покупки.

**Таблица скидок:**

| Сумма покупки | Скидка |
| ------------- | ------ |
| 5000 – 9999 | 5% |
| 10000 – 14999 | 10% |
| 15000 и более | 15% |

**Как пользоваться:** для каждого товара введите название, цену и количество. Затем на вопрос
`Добавить ещё один товар? (да/нет):` ответьте `да`, чтобы продолжить, или `нет`, чтобы
завершить ввод. Программа выведет стоимость каждого товара, общую стоимость, процент скидки,
размер скидки и итоговую стоимость.

**Пример работы:**

```
========================================
Расчёт стоимости покупки
========================================
Скидки: 5000-9999 -> 5%, 10000-14999 -> 10%, от 15000 -> 15%
Введите название товара: Клавиатура
Введите цену: 4500
Введите количество: 1
Добавить ещё один товар? (да/нет): да
Введите название товара: Мышь
Введите цену: 2000
Введите количество: 2
Добавить ещё один товар? (да/нет): нет

Клавиатура: 4500
Мышь: 4000
Общая стоимость: 8500
Скидка: 5%
Размер скидки: 425
Итоговая стоимость: 8075

Посчитать ещё одну покупку? (да/нет): нет
Программа завершена
```

**Обработка ошибок:**

| Ситуация | Поведение |
| -------- | --------- |
| Пустое название товара | `Ошибка: название не может быть пустым.` |
| Цена не число | `Ошибка: цена должна быть числом.` |
| Цена ≤ 0 | `Ошибка: цена должна быть больше нуля.` |
| Количество не целое число | `Ошибка: количество должно быть целым числом.` |
| Количество ≤ 0 | `Ошибка: количество должно быть больше нуля.` |

> Цена принимается и с запятой, и с точкой в качестве разделителя (`199,90` → `199.9`).
> Целые суммы выводятся без копеек, дробные — с двумя знаками.
